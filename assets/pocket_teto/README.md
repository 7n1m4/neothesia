## Sample Format

- Format: WAV (PCM)
- Sample rate: 44.1 kHz or 48 kHz (will be resampled automatically)
- Channels: Mono or Stereo (will be mixed to mono)
- Bit depth: 16-bit or 24-bit

## Source

Extract these from the Kasane Teto UTAU voicebank (available from the official Teto website or UTAU database).

The round-robin playback will cycle through these files in alphabetical order.
